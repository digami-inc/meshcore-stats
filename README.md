# meshcore-stats

Private project for Inciema tower MeshCore telemetry tools.

## Layout

- `ui/` - UI app and related service files
- `collector/` - collector / ingest side for repeater telemetry polling
- `sql/` - schema updates and migrations
- `docs/` - notes and operational docs

## Secrets

Do not commit passwords, private keys, or host-specific env files.
Use example env files instead.
